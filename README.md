# PartyJoin

PartyJoin is an ACT plugin for FFXIV that sends Discord webhook notifications when a party join packet is received and can display incoming packet data for diagnostics.

The project targets .NET Framework 4.7.2 and references the ACT and FFXIV ACT Plugin assemblies from `References/ACT`.

See the [English usage guide](docs/plugin-usage-en.md) for installation and configuration instructions.
